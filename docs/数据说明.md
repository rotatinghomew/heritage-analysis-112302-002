# 古建复原图的证据冲突与展签授权

本地数据与术语材料供业务人员整理分析资料使用，所有记录均为合成样例。

## 输入

`fixtures/` 包含若干 CSV 文件。文件首行为字段名，空值表示来源没有给值。工具按表头识别文件角色，同类文件可以拆成多个（如 `primary.csv`、`primary-2.csv`），载入时合并。记录用于说明输入结构和实体关联，不含统计结论。

### 证据记录（如 `primary.csv`、`primary-2.csv`）

字段：`record, source, parent, object, phase, claim, relation, year, access`。

- `parent` 指向来源家族根（同一原件）。复制记录沿同一原件形成一个家族，不按引用次数累加独立支持。
- `claim` 为 `supports` 或 `contradicts`，表明记录支持或反驳的是哪个构件（`object`）与期段（`phase`）。
- `year` 是来源对所见遗构的记年；记年落在期段范围外的记录对该期段不适用。空值表示年代缺报：缺报既不算支持也不算反驳，与“记年为零”不同。
- `access` 为 `research`（仅供馆内研究）或 `exhibition`。

### 解释（如 `support-1.csv`、`support-2.csv`）

字段：`interpretation, object, phase, requires, conflicts`。`requires` 列出该解释依据的证据记录；`conflicts` 列出声明互斥的其他解释。同一构件的多个解释互为同层备选。

### 期段与年代区间

`phases.csv`：`phase, start, end`（闭区间）。`interpretation-dates.csv`：`interpretation, start, end`，给出解释所断言形态的年代区间；缺省时退回期段范围。日期区间不重叠的解释不能合在一张确定性复原图中。

### 建造先后与抄录存疑

`ordering.csv`：`before, after`，表示 before 解释的建造必须先于 after 解释；先后条件成环的组合不成立。`dependency-doubts.csv`：`source_a, source_b, note`，登记来源之间存疑的抄录关系，工具据此显示依赖风险（若关系成立，独立支持会如何缩水）。

### 重新断代

`updates.csv`：`source, year, reason`。`impact` 命令据此改定来源记年，重新评估解释与展签；原始输入保持不变。

### 展签

`labels.csv`：`label, version, status, issued_to, issued_on, supersedes`。`status` 为 `draft`、`approved` 或 `issued`；已签发版本的内容不可改写，更正只能另起新版本（`supersedes` 指向被接替版本）。

`label-statements.csv`：`label, version, statement, group, kind, interpretation, text, image_source, licensee, display_scope, cites`。

- `kind` 为 `certainty`（确定性陈述）或 `alternative`（多说法之一）；同 `group` 的语句互为备选。
- `image_source` 是复制上展签的原图/摘录来源；仅供馆内研究的来源不得出现在展签上。
- `licensee`（许可对象）与 `display_scope`（展示范围）在复制材料或引用限制材料时必须保留。
- `cites` 是引文（证据记录号，分号分隔）。

## 解释

有效范围、证据和审批状态按业务记录本身判断。不同表中的同一标识用于关联记录，不代表两份独立观察。资料存在未知、零和缺报的区别：空单元格按字段语义处理（如 `conflicts` 为空表示无声明互斥，`year` 为空表示年代缺报）。

## 输出

`issued/` 保存已签发展签的快照（内容寻址，文件名含内容哈希）。快照是巡展方实际收到内容的唯一凭据；`verify` 校验登记内容与快照一致，`as-issued` 按原内容回查。任何对旧稿的改正都不得写回已签发版本。
